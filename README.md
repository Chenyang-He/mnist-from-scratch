# MNIST from Scratch

Building a multilayer perceptron (MLP) from scratch using only NumPy to classify handwritten digits (MNIST). No deep learning frameworks — every forward pass, backward gradient, and weight update is implemented manually.

## Goals

- Implement backpropagation by hand and verify it with numerical gradient checking
- Achieve ≥95% accuracy on MNIST test set
- Reimplement the same model in PyTorch and write a comparison analysis
